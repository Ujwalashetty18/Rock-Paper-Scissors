# 🎮 Rock-Paper-Scissors Game

A simple and interactive **Rock-Paper-Scissors** game where the player competes against the computer. The computer randomly selects one of the three choices, and the game determines the winner based on the classic rules.

## 🚀 Features

* 🪨 Rock, 📄 Paper, and ✂️ Scissors choices
* 🤖 Computer makes a random choice
* 🏆 Automatically determines the winner
* 📊 Displays player and computer scores
* 🔄 Reset/restart game functionality
* 🎨 Simple and user-friendly interface
* ⚡ Instant result after every round
* 📱 Responsive design

## 🎯 Game Rules

The game follows the standard Rock-Paper-Scissors rules:

| Player      | Computer    | Result      |
| ----------- | ----------- | ----------- |
| 🪨 Rock     | ✂️ Scissors | Player Wins |
| 📄 Paper    | 🪨 Rock     | Player Wins |
| ✂️ Scissors | 📄 Paper    | Player Wins |
| Same Choice | Same Choice | Draw        |

### Example

* Rock 🪨 beats Scissors ✂️
* Scissors ✂️ beats Paper 📄
* Paper 📄 beats Rock 🪨

## 🎮 How to Play

1. Open the game in your browser.
2. Choose **Rock**, **Paper**, or **Scissors**.
3. The computer randomly selects its choice.
4. The game compares both choices.
5. The winner is displayed.
6. Continue playing to increase your score.
7. Use the reset option to start a new game.

## 🧠 Game Logic

The computer's choice is generated randomly from:

```javascript
["rock", "paper", "scissors"]
```

The selected choices are then compared using the standard game rules to determine whether the result is:

* **You Win 🎉**
* **You Lose 😔**
* **Draw 🤝**
